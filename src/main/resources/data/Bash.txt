Create EC2 Instance
-------------------
Configure the Instance
Amazon Machine Image (AMI):
Choose Amazon Linux 2 or Ubuntu 22.04 LTS

Instance type:
t2.micro (free tier eligible) or larger as needed

Key pair (login):
Select existing or create a new key pair – download the .pem file

Network settings:

Enable Auto-assign Public IP

Security group: Create new or select existing:

Add rules:

SSH (port 22) – your IP

HTTP (port 80) – 0.0.0.0/0

Custom TCP (port 8080) – 0.0.0.0/0 (for Spring Boot app)

HTTPS TCP (port 443) - 0.0.0.0/0

Enable and Start the Service
============================
sudo systemctl daemon-reexec			# After update systemd file
sudo systemctl daemon-reload                    # Reload systemd to recognize the new service
sudo systemctl restart secure-prints            # Restart the app after update systemd file

sudo systemctl start secure-prints              # Start the app now
sudo systemctl enable secure-prints             # Start it automatically on boot


Verify
======
sudo systemctl status secure-prints
journalctl -u secure-prints -f


Stop Service
============
sudo systemctl stop secure-prints


Disable it from Starting on Boot
================================
sudo systemctl disable secure-prints

Configure Nginx (Optional for SPA Routing)
------------------------------------------
sudo nano /etc/nginx/nginx.conf

Under server { ... } block

server_name  secure-prints.com www.secure-prints.com

location /.well-known/acme-challenge/ {
    root      /usr/share/nginx/html;
    index     index.html index.htm;
    try_files $uri $uri/ /index.html;
}

location /secure-prints/ {
    proxy_pass http://localhost:8080/secure-prints/;
    proxy_http_version 1.1;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
}
